# 视觉规范重新审校（2026-10-09）

依据 [OrcaSVN 视觉规范](visual-design-system.md)，对 v0.6.4 源码和实际 Vue 浏览器页面重新审校。审校基线为 `d30e26d`，本记录包含本次修复后的结果，不修改以前的审校结论。

## 范围与方法

检查设计变量、全局样式、主布局、共享组件及工作区、检出、提交、更新、日志、对比、贮藏、追溯、设置九个页面。浏览器使用本地 Vite 和 Python Playwright / Chromium，无原生窗口边框。

在独立浏览器会话中模拟 Tauri 命令桥接，提供七种文件状态、日志、差异、追溯及未版本文件预览；长路径和作者名约 250–330 个字符。所有数据均为示例，没有运行 SVN 命令、访问远端仓库或修改真实工作副本。

窗口为 1280 × 900、390 × 900，分别检查浅色和深色：九个页面的空工作区状态共 36 个场景；除检出外八个页面的模拟数据状态共 32 个场景。对比和追溯页手动填入长路径后加载数据；日志打开提交详情，贮藏打开创建弹窗。浏览器边界检查允许导航、表格、代码在所属区域内横向滚动，额外检查弹窗外壳上下边界及正文宽度。

## 发现与修复

| 问题 | 修复及目的 |
| --- | --- |
| 日志详情两列元数据在窄窗口下挤压长作者名；内容很高时底部关闭按钮位于首屏之外 | 元数据改为单列，允许长内容换行；非全屏弹窗限制可用高度，正文独立滚动，标题和底部按钮不收缩 |
| 贮藏创建工具栏在 390px 下把说明挤成逐字换行 | 窄窗口按纵向排列说明和操作，操作允许换行 |
| 贮藏长路径与分块计数争抢宽度；多行路径仍使用固定高度复选框 | 路径可任意位置换行，复选框随内容增高，分块计数保持单行 |
| 工作区差异标题长路径挤出统计标签；追溯路径缺少独立的省略区域 | 路径省略显示，提供完整 `title`，图标和统计保持宽度 |
| 工作区关闭按钮、贮藏更多操作按钮缺少可访问名称 | 复用现有多语言文案补齐 `aria-label` |
| 工作区局部导航及近期提交操作圆角为 3–4px，贮藏名称和追溯组合输入框圆角为 12px | 对这些交互控件统一使用 8px 变量；工作区局部导航文字改用 13px 标签变量 |
| 新差异查看器新增、删除代码文字未使用配对状态色 | 改用对应状态文字变量，保留行号和 `+` / `-` 标记 |
| 日志加载状态固定蓝色，路径和代码字体在多个页面重复声明 | 日志使用主色变量；全局和相关页面复用等宽字体变量 |

## 尚未完成的规范迁移与验收

本轮修复了上述问题，但不能据此认定所有实现均符合规范。

- 全局样式和工作区仍存在分散的重复声明；部分历史样式依赖选择器优先级及 `!important`，后续应按组件整理。
- 部分页面卡片仍局部指定 18px 圆角，更新页摘要容器仍为 6px；与普通容器 12px 要求尚未完全一致。历史字号、间距、边框颜色也未全部迁移到变量。
- 深色主题通用 `.el-tag` 覆盖仍会把部分业务类型标签变为中性色；文字保留了状态含义，但仍需按类型核对颜色语义。
- 未覆盖所有语言、所有弹层、全部业务错误及所有键盘快捷键；没有屏幕阅读器或全页面对比度扫描。
- 未在真实 Tauri 窗口验收检出、提交、更新、贮藏保存/应用、还原、删除、错误恢复，也未验证不同操作系统的字体和原生滚动行为。

后续先完成真实桌面受影响流程验收，再逐步收敛历史样式；保留本轮的模拟数据边界，不把浏览器结果计作桌面集成通过。
