# OrcaSVN v0.6.5

## 自 v0.6.4 以来的改进

- 新增 `orcasvn` 命令入口和版本更新检查，可从设置页检查新版本。
- 提交时可选择自动将勾选的缺失文件安排删除，默认关闭；失败时保护原有工作副本修改。
- Windows 状态检查增加普通权限下的增量回退，并修复目录变更通知的可靠性。
- 工作区加载失败时显示具体错误；无法读取本地版本时仍保持工作区打开，错误提示对应实际失败的操作。
- 修正远端待更新提交的判断，避免部分提交后漏掉尚未拉取的改动。
- 更新产生冲突时显示警告和冲突路径；状态刷新失败时保留已报告的冲突信息。
- 修复差异视图的原文件行号、以加减号开头的正文分类，以及行号栏和横向滚动宽度。
- 修复有效 UTF-8 文本被 SVN 自动识别为二进制后无法显示正文的问题，并减少不必要的属性检查。
- SVN 命令成功但没有输出时提供完成反馈；改进对话框、键盘操作和界面语言同步。

## Changes since v0.6.4

- Add the `orcasvn` command entry and release update checks, including a check from Settings.
- Optionally schedule selected missing files for deletion on commit. The setting is off by default, and failures protect existing working-copy changes.
- Add an incremental Windows status fallback without elevated permissions and improve directory change notification reliability.
- Show specific workspace loading errors, keep the workspace open when its revision cannot be read, and associate error messages with the failed operation.
- Correct pending remote commit detection so partial commits do not hide changes that still need updating.
- Warn about update conflicts and list affected paths, retaining reported conflicts when status refresh fails.
- Fix original-file diff line numbers, classification of content beginning with plus or minus signs, and gutter and horizontal scrolling widths.
- Restore text diffs for valid UTF-8 files automatically marked as binary by SVN and avoid unnecessary property checks.
- Report completion for SVN commands that succeed without output, and improve dialogs, keyboard access, and interface language synchronization.
