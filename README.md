# OrcaSVN（egui 预览版）

本分支是 OrcaSVN 的原生 Rust + [egui](https://github.com/emilk/egui) 重写版本，**只以预发布版本发布**（`vX.Y.Z-alpha.N` / `-beta.N` / `-rc.N`），用于收集长期使用反馈。

稳定版（Tauri + Vue）在 [`main`](https://github.com/wustites/OrcaSVN/tree/main) 分支维护。两个分支独立开发，互不合并。

- 构建与功能说明：[`orcasvn-egui/README.md`](orcasvn-egui/README.md)
- 下载：[GitHub Releases](https://github.com/wustites/OrcaSVN/releases) 中的预发布版本
- 反馈：[Issues](https://github.com/wustites/OrcaSVN/issues)，标题请注明 “egui”
